# Розширення Chrome

Пошук по обліку в боковій панелі: серійник, отримувач, склад, ящики, доставки.
Живе в `extension/`, збірки не потребує. Окремого входу немає: працює сесія сайту.

## Встановлення

1. Отримайте папку `extension` (архівом або з репозиторію) і розпакуйте її.
2. Відкрийте `chrome://extensions`, увімкніть «Режим розробника».
3. «Завантажити розпаковане» → оберіть папку `extension`.
4. Увійдіть на сайт у цьому ж профілі Chrome.

## Користування

- Кнопка на панелі або `Alt+Shift+O` відкриває пошук.
- Виділіть текст на будь-якій сторінці → правий клік → «Шукати в Обліку».
- Без запиту в панелі видно «Повідомлення для чату» з кнопкою «Копіювати».
- Цифра на кнопці: термінові посилки, оновлюється раз на 30 хвилин.

## Що варто знати

- Сесія закінчується за вікнами сайту. Тоді панель покаже кнопку входу.
- Адреса сайту записана в `extension/format.js` і `extension/manifest.json`. Новий домен
  означає нову версію розширення в обох місцях.
- Після оновлення папки натисніть «Оновити» на картці розширення.
