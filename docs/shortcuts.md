# Закладка й швидкі команди

Заміна розширенню там, де його немає: Safari на iPhone і Mac. Ні Xcode, ні акаунт
розробника не потрібні. Спершу додайте сайт на екран «Домой»: Поділитися → «На екран „Домой“».

## Закладка для Safari на Mac

Створіть будь-яку закладку, потім змініть її адресу на цей рядок:

```
javascript:location.href='https://oblik-brown.vercel.app/?q='+encodeURIComponent(String(getSelection()).trim())
```

Виділіть текст на сторінці й натисніть закладку.

## Команда «Шукати в Обліку»

Застосунок «Команди» → «+». У параметрах команди увімкніть «Показувати на аркуші
„Поділитися“», приймати «Текст». Далі дії:

1. «Кодувати URL»: вхідні дані команди.
2. «URL»: `https://oblik-brown.vercel.app/?q=` і змінна «Закодований URL».
3. «Відкрити URL-адреси».

Користування: виділити текст → Поділитися → «Шукати в Обліку».

## Команда «Каса»

Текст для чату з `/api/fund`. Сторінка фонду відкрита без входу, тому команда працює завжди.

1. «Отримати вміст URL-адреси»: `https://oblik-brown.vercel.app/api/fund`.
2. «Отримати значення словника»: ключ `report`.
3. «Скопіювати в буфер».
4. «Поділитися»: у меню оберіть Signal і групу. Цей крок можна прибрати.

## Як роздати

У «Командах» натисніть команду й утримуйте → Поділитися → «Скопіювати посилання iCloud».
Посилання відкриється в кожного, хто його отримає: не викладайте його у відкриті чати.
