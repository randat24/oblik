# Облік майна — сайт на Vercel

Next.js застосунок, який працює напряму з вашою Google Таблицею через Google Sheets API.
Без Apps Script, без банера Google, зі своїм доменом і захистом паролем.

---

## Крок 1. Сервісний акаунт Google (10 хв)

Це «робот», від імені якого сайт читатиме й писатиме у таблицю.

1. Відкрийте https://console.cloud.google.com/
2. Вгорі створіть новий проєкт (назва будь-яка, напр. `oblik-mayna`)
3. Меню → **APIs & Services → Library** → знайдіть **Google Sheets API** → **Enable**
4. Меню → **APIs & Services → Credentials** → **Create Credentials** → **Service account**
   - Ім'я: `oblik`
   - **Create and continue** → роль не потрібна → **Done**
5. Клацніть на створений акаунт → вкладка **Keys** → **Add key → Create new key → JSON** → завантажиться файл
6. Відкрийте цей JSON — звідти знадобляться два поля: `client_email` і `private_key`

## Крок 2. Дати роботу доступ до таблиці

1. Відкрийте вашу Google Таблицю
2. **Поділитися (Share)**
3. Вставте значення `client_email` з JSON (щось на кшталт `oblik@oblik-mayna.iam.gserviceaccount.com`)
4. Права: **Редактор**
5. Зніміть галочку «Сповістити» → **Поділитися**

## Крок 4. Vercel

1. https://vercel.com → увійдіть через GitHub
2. **Add New → Project** → оберіть репозиторій `oblik` → **Import**
3. **Environment Variables** — додайте чотири змінні:

| Name | Value |
|---|---|
| `SPREADSHEET_ID` | `1E5k8fE2LnHO4PsSOT9RgtMZZNOfNYQ7Oj1ifO0gfIhY` |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | `client_email` з JSON |
| `GOOGLE_PRIVATE_KEY` | `private_key` з JSON — **повністю, разом з `-----BEGIN...`** |
| `APP_PASSWORD` | пароль для входу на сайт |
| `SESSION_SECRET` | будь-який довгий випадковий рядок |
| `GOOGLE_DRIVE_FOLDER_ID` | ID папки для фото — див. «Фото на складі» |
| `GOOGLE_OAUTH_CLIENT_ID` | для фото — див. «Фото на складі» |
| `GOOGLE_OAUTH_CLIENT_SECRET` | для фото — див. «Фото на складі» |
| `GOOGLE_OAUTH_REFRESH_TOKEN` | видає `/api/oauth/start` — див. «Фото на складі» |
| `GOOGLE_IMPERSONATE_USER` | лише для Google Workspace — див. «Фото на складі» |

> **Важливо про `GOOGLE_PRIVATE_KEY`:** копіюйте значення з JSON як є, разом із символами `\n`
> (код сам перетворить їх на переноси рядків), але **без лапок по краях**.
>
> У файлі `.env` лапки — частина синтаксису, і при читанні вони відкидаються.
> А в полі Vercel значенням стає рівно те, що ви вставили: якщо залишити лапки,
> вони потраплять усередину ключа й він перестане читатися.
>
> Тобто у Vercel вставляйте починаючи з `-----BEGIN PRIVATE KEY-----` і
> закінчуючи `-----END PRIVATE KEY-----\n`.

4. **Deploy** → за хвилину сайт готовий

## Крок 5. Свій домен (за бажанням)

Project → **Settings → Domains** → додайте домен → пропишіть DNS-записи, які покаже Vercel.

## Налаштування листів

Файл `lib/sheets.js`, масив `SHEET_CONFIGS` — назви мають **точно** збігатися з ярличками вкладок:

```js
export const SHEET_CONFIGS = [
  { name: 'Радейки', kind: 'items' },
  { name: 'ПНВ', kind: 'items' },
  { name: 'Тепловізори', kind: 'items' },
  { name: 'Автомобільні', kind: 'items' },
  { name: 'Дрони', kind: 'items', noIssue: true },
  { name: 'Майно роти', kind: 'ledger' },
  { name: 'майно не облік', kind: 'items', maskPasswords: true },
  { name: 'Кропива', kind: 'items' },
  { name: 'Склад', kind: 'warehouse' },
];
```

- `kind: 'items'` — звичайний список карток
- `kind: 'ledger'` — відомість із залишками та списанням
- `kind: 'warehouse'` — склад із фото та QR
- `noIssue: true` — сховати кнопки «Видати / Прийняти»
- `hideStatus: true` — сховати колонку «Статус» у картках, фільтрах і пошуку
- `maskPasswords: true` — приховати колонки з паролями

Колонки шукаються **за заголовками**, а не за номерами — можна переставляти місцями.

## Що працює

- **🔍 Пошук** — живий, без кнопки: шукає сам після 2 символів, є хрестик для очищення.
  S/N, позивний, модель, місце, примітка. Групує: за номером / рахується за / інші згадки.
  «Відкрити лист» переходить на потрібний лист і підсвічує саме той рядок
- **Звичайні листи** — картки, фільтри за статусом, пошук, редагування на місці, «Видати» / «Прийняти» / «Видалити», додавання
- **Майно роти** — залишки, списання з датою й перевіркою залишку, редагування позиції в картці, видалення
- **Склад** — унікальні коди, фільтр за пріоритетом, фото на весь екран, завантаження фото з телефона, QR-код із друком
- **🕘 Журнал** — що, де й коли змінилося, найновіші зверху, з пошуком
- **Скасування видалення** — після видалення внизу зʼявляється «Повернути»,
  запис стає на те саме місце. Кнопка живе 9 секунд
- **Сповіщення** — кожна дія підтверджується повідомленням унизу праворуч

## Гарячі клавіші

| Клавіші | Дія |
|---|---|
| `Ctrl/Cmd + F` або `/` | Фокус у поле пошуку |
| `Ctrl/Cmd + N` | Новий запис у поточній вкладці |
| `Esc` | Очистити пошук / закрити вікно |

## Журнал змін

Вкладка **Журнал** показує історію: дата, час, лист, рядок, дія та «було → стало».
Записується автоматично при редагуванні, видачі, прийомі, списанні, додаванні,
видаленні та відновленні.

Дані лежать у вкладці **Журнал** вашої таблиці — вона створюється сама при першій зміні,
нічого налаштовувати не треба. Час київський.

> Зараз журнал не фіксує **хто** саме змінив: у всіх один спільний пароль,
> тож сайт не розрізняє людей. Якщо це знадобиться — можна зробити окремий пароль
> на кожного, і тоді в журналі зʼявиться колонка з іменем.

## QR-коди

Кнопка **QR** на картці ящика генерує код із посиланням `https://ваш-домен/?box=КОД`.
Після сканування сайт відкриває вкладку «Склад» і показує саме цей ящик —
згори буде смужка «Відскановано ящик …» з кнопкою «Показати всі».

## Фото на складі

Фото можна **завантажити прямо з телефона**: на картці ящика кнопка «Завантажити фото»
відкриває камеру або галерею. Перед відправкою фото стискається у браузері
(до 1600 px, JPEG) — тож навіть велике фото з телефона вантажиться швидко.
Поле для вставки посилання лишилося — старі посилання `lh3.googleusercontent.com` працюють.

Фото зберігаються на вашому **Google Диску**. У таблиці лежить не посилання, а
внутрішній ідентифікатор файлу, і показує фото маршрут `/api/photo` — лише тому,
хто увійшов на сайт. Сам файл на Диску нікому не «розшарений», подивитися на нього
напряму без входу на сайт не можна.

> **Чому не досить просто поділитися папкою із сервісним акаунтом.** У сервісного
> акаунта немає власного місця на Диску. Якщо він спробує створити файл у звичайній
> папці, Google відмовить: `Service Accounts do not have storage quota`. Місце має
> належати комусь із квотою — або Спільному диску (лише платний Workspace), або
> живій людині. Тому основний спосіб нижче — авторизація від вашого імені: саме так
> працювала й стара версія на Apps Script.

Спершу, якщо ще не робили цього для Таблиці: Google Cloud Console → **APIs & Services →
Library** → знайдіть **Google Drive API** → **Enable** (той самий проєкт, що й для
Sheets API з Кроку 1).

### Налаштування (працює і зі звичайним @gmail.com)

1. Google Cloud Console → **APIs & Services → OAuth consent screen**
   - User type: **External**
   - Заповніть назву застосунку й свою пошту
   - **Опублікуйте застосунок** (кнопка «Publish app»). Якщо лишити режим
     «Testing», refresh-токен протухатиме **кожні 7 днів**, і фото перестануть
     вантажитись. Scope `drive.file` не потребує перевірки Google, тож публікація
     проходить одразу
2. **APIs & Services → Credentials → Create Credentials → OAuth client ID**
   - Application type: **Web application**
   - Authorized redirect URIs: `https://ВАШ-ДОМЕН/api/oauth/callback`
     (рівно так, з тим самим доменом, з якого відкриваєте сайт)
3. Додайте у Vercel дві змінні з отриманих значень і зробіть **Redeploy**:
   - `GOOGLE_OAUTH_CLIENT_ID`
   - `GOOGLE_OAUTH_CLIENT_SECRET`
4. Відкрийте на сайті адресу **`/api/oauth/start`** (треба бути залогіненим),
   підтвердіть доступ у Google
5. Застосунок сам створить теку «Облік майна — фото» на вашому Диску й покаже
   два значення. Додайте їх у Vercel і зробіть **Redeploy**:
   - `GOOGLE_OAUTH_REFRESH_TOKEN`
   - `GOOGLE_DRIVE_FOLDER_ID`

> **Чому теку створює застосунок, а не ви.** Scope `drive.file` дає доступ лише до
> файлів, які застосунок створив сам. У теку, зроблену руками, він писати не зможе —
> отримаєте `File not found`. Тому теку заводить крок 5.

### Якщо у вас Google Workspace

Тоді доступні ще два варіанти замість кроків вище:

- **Спільний диск.** Створіть Shared Drive (окремий розділ ліворуч, не всередині
  «Мій диск»), дайте сервісному акаунту роль **Менеджер контенту**, і вкажіть
  `GOOGLE_DRIVE_FOLDER_ID` — теку в ньому. Більше нічого не треба.
- **Делегування.** Admin console → **Security → Access and data control → API
  controls → Domain-wide delegation**, Client ID сервісного акаунта і scope
  `https://www.googleapis.com/auth/drive.file`. Далі змінна `GOOGLE_IMPERSONATE_USER`
  з робочою поштою. На звичайному `@gmail.com` це **не працює** — Google відповість
  `invalid_grant: account not found`.

`GOOGLE_DRIVE_FOLDER_ID` можна вставляти як завгодно — чистим ID або цілим
посиланням на папку, код сам витягне потрібне.

Поки папка не задана, кнопка завантаження покаже
«Не підключено Google Drive для фото», а поле з посиланням працюватиме як і раніше.

## Безпека

- Вхід за паролем (`APP_PASSWORD`), сесія на 30 днів у HttpOnly-cookie
- Ключ сервісного акаунта лежить у змінних оточення Vercel, у код не потрапляє
- Репозиторій тримайте приватним
- Якщо `APP_PASSWORD` не заданий — захист вимкнено, сайт відкритий усім
